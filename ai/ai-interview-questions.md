# AI 面试题集

## 一、机器学习基础

### 1.1 监督学习

**Q1：什么是偏差-方差权衡？**
- 偏差：模型预测与真实值的偏离程度
- 方差：模型对训练数据变化的敏感度
- 权衡：低偏差高方差 vs 高偏差低方差
- 解决：正则化、集成学习

**Q2：L1 和 L2 正则化的区别？**
- L1（Lasso）：绝对值惩罚，产生稀疏解
- L2（Ridge）：平方惩罚，权重趋近于零但不为零
- 应用：特征选择（L1）、防止过拟合（L2）

**Q3：什么是交叉验证？为什么使用？**
- 定义：将数据分为 K 折，轮流作为验证集
- 优点：更可靠的模型评估
- 变体：K 折、留一法、分层

**Q4：如何处理类别不平衡？**
- 过采样：SMOTE
- 欠采样：随机采样
- 代价敏感：调整类别权重
- 集成方法：EasyEnsemble

**Q5：什么是特征选择？方法有哪些？**
- 定义：选择最相关的特征
- 方法：过滤法、包装法、嵌入法
- 优点：减少过拟合、提高效率

### 1.2 无监督学习

**Q6：K-Means 算法的步骤？**
1. 随机初始化 K 个中心
2. 将每个点分配到最近的中心
3. 更新中心为簇的均值
4. 重复直到收敛

**Q7：如何选择 K 值？**
- 肘部法则：观察 SSE 变化
- 轮廓系数：评估簇质量
- 业务需求：根据实际需要

**Q8：PCA 的原理？**
- 目标：找到最大方差的方向
- 步骤：中心化、协方差矩阵、特征分解
- 应用：降维、可视化

### 1.3 集成学习

**Q9：Bagging 和 Boosting 的区别？**
- Bagging：并行训练，减少方差（随机森林）
- Boosting：串行训练，减少偏差（XGBoost）
- 选择：根据问题类型

**Q10：随机森林的原理？**
- 构建：多棵决策树投票
- 随机性：样本随机、特征随机
- 优点：减少过拟合、特征重要性

**Q11：XGBoost 的优化？**
- 正则化：L1、L2
- 缺失值处理：自动学习方向
- 并行化：特征并行
- 剪枝：限制树深度

## 二、深度学习

### 2.1 神经网络基础

**Q12：为什么需要激活函数？**
- 引入非线性
- 增加模型表达能力
- 常用：ReLU、Sigmoid、Tanh

**Q13：ReLU 的优点？**
- 计算简单
- 缓解梯度消失
- 稀疏激活

**Q14：什么是梯度消失和梯度爆炸？**
- 梯度消失：梯度指数衰减
- 梯度爆炸：梯度指数增长
- 解决：归一化、残差连接、梯度裁剪

**Q15：Batch Normalization 的作用？**
- 加速训练
- 稳定梯度
- 允许更大的学习率

### 2.2 CNN

**Q16：卷积层的作用？**
- 局部连接：提取局部特征
- 权重共享：减少参数
- 平移不变性：位置无关

**Q17：池化层的作用？**
- 降维：减少计算量
- 不变性：小的平移不变
- 类型：最大池化、平均池化

**Q18：ResNet 的创新？**
- 残差连接：跳跃连接
- 解决：深层网络退化
- 效果：训练更深的网络

### 2.3 RNN 和序列模型

**Q19：RNN 的问题？**
- 梯度消失：长序列问题
- 长期依赖：难以捕获远距离关系
- 解决：LSTM、GRU

**Q20：LSTM 的门控机制？**
- 遗忘门：决定丢弃什么信息
- 输入门：决定添加什么信息
- 输出门：决定输出什么信息

**Q21：Transformer 的创新？**
- 自注意力：并行计算
- 位置编码：序列位置
- 多头注意力：多表示子空间

### 2.4 优化和训练

**Q22：学习率调度策略？**
- 学习率衰减：逐步减小
- 余弦退火：周期性变化
- 预热：开始小，逐渐增大

**Q23：如何防止过拟合？**
- 数据增强：增加数据量
- 正则化：L1、L2、Dropout
- 早停：验证集性能不再提升时停止
- 集成：多个模型平均

**Q24：什么是迁移学习？**
- 定义：将知识迁移到新任务
- 方法：预训练 + 微调
- 优点：减少数据需求

## 三、自然语言处理

### 3.1 文本处理

**Q25：什么是词嵌入？**
- 定义：将词映射到向量空间
- 方法：Word2Vec、GloVe
- 优点：捕获语义关系

**Q26：BPE 分词的原理？**
- 过程：迭代合并最频繁的字符对
- 优点：处理未知词
- 应用：GPT、BERT

**Q27：TF-IDF 的原理？**
- TF：词在文档中的频率
- IDF：词在语料库中的逆频率
- 应用：文本特征提取

### 3.2 语言模型

**Q28：什么是语言模型？**
- 定义：预测下一个词的概率
- 类型：自回归、掩码
- 应用：文本生成、理解

**Q29：BERT 和 GPT 的区别？**
- BERT：双向，掩码语言模型
- GPT：单向，自回归语言模型
- 应用：理解 vs 生成

**Q30：什么是注意力机制？**
- 定义：关注输入的重要部分
- 计算：Query、Key、Value
- 应用：Transformer

### 3.3 预训练模型

**Q31：什么是预训练？**
- 定义：在大规模数据上训练
- 作用：学习通用表示
- 应用：迁移学习

**Q32：什么是微调？**
- 定义：在预训练模型上继续训练
- 方法：全量微调、LoRA
- 应用：特定任务

**Q33：什么是提示工程？**
- 定义：设计有效的提示
- 技巧：清晰指令、示例、格式
- 应用：大语言模型

## 四、计算机视觉

### 4.1 图像分类

**Q34：CNN 在图像分类中的应用？**
- 卷积层：提取特征
- 池化层：降维
- 全连接层：分类

**Q35：什么是数据增强？**
- 定义：增加训练数据
- 方法：旋转、翻转、裁剪
- 作用：减少过拟合

**Q36：什么是迁移学习在 CV 中的应用？**

- 微调：特定任务微调
- 优点：减少数据需求

**Q37：YOLO 的原理？**
- 单次检测：将图像分为网格
- 预测：每个网格预测边界框
- 优点：速度快

**Q38：什么是 IoU？**
- 定义：交并比
- 计算：交集 / 并集
- 应用：评估检测精度

**Q39：什么是 NMS？**
- 定义：非极大值抑制
- 过程：去除重叠的边界框
- 应用：目标检测后处理

### 4.3 图像生成

**Q40：GAN 的原理？**
- 生成器：生成假数据
- 判别器：区分真假
- 训练：对抗训练

**Q41：什么是扩散模型？**
- 过程：前向加噪，反向去噪
- 优点：生成质量高
- 应用：图像生成

## 五、强化学习

### 5.1 基础概念

**Q42：什么是强化学习？**
- 定义：通过与环境交互学习
- 组件：状态、动作、奖励
- 目标：最大化累积奖励

**Q43：什么是马尔可夫决策过程？**
- 定义：状态转移只依赖当前状态
- 组件：状态、动作、转移、奖励
- 应用：强化学习建模

**Q44：什么是探索与利用？**
- 探索：尝试新动作
- 利用：选择已知最优动作
- 平衡：ε-贪心、UCB

### 5.2 经典算法

**Q45：Q-Learning 的原理？**
- 目标：学习 Q 值函数
- 更新：Q(s,a) ← Q(s,a) + α[r + γmaxQ(s',a') - Q(s,a)]
- 特点：无模型、离线策略

**Q46：策略梯度的原理？**
- 目标：直接优化策略
- 梯度：∇J = E[∇logπ(a|s) * R]
- 优点：处理连续动作空间

**Q47：PPO 的原理？**
- 目标：限制策略更新幅度
- 方法：裁剪目标函数
- 优点：稳定训练

### 5.3 深度强化学习

**Q48：DQN 的创新？**
- 经验回放：打破数据相关性
- 目标网络：稳定训练
- 应用：游戏 AI

**Q49：A3C 的原理？**
- 异步：多个 agent 并行训练
- Actor-Critic：策略 + 值函数
- 优点：高效训练

## 六、大语言模型

### 6.1 架构

**Q50：Transformer 的架构？**
- 编码器：双向注意力
- 解码器：单向注意力
- 应用：NLP、CV

**Q51：什么是自注意力？**
- 计算：QK^T / √d * V
- 作用：捕获长距离依赖
- 优点：并行计算

**Q52：什么是多头注意力？**
- 定义：多个注意力头并行
- 作用：关注不同表示子空间
- 应用：Transformer

### 6.2 训练

**Q53：什么是预训练目标？**
- 掩码语言模型：预测被掩码的词
- 下一句预测：判断两句是否连续
- 自回归：预测下一个词

**Q54：什么是 RLHF？**
- 过程：训练奖励模型，优化策略
- 作用：对齐人类偏好
- 应用：ChatGPT

**Q55：什么是 LoRA？**
- 定义：低秩适配
- 方法：冻结原始参数，添加低秩矩阵
- 优点：参数高效

### 6.3 应用

**Q56：什么是提示工程？**
- 定义：设计有效的提示
- 技巧：清晰指令、示例、格式
- 应用：大语言模型

**Q57：什么是 RAG？**
- 定义：检索增强生成
- 过程：检索相关文档，生成答案
- 优点：减少幻觉

**Q58：什么是 Agent？**
- 定义：能够自主行动的系统
- 组件：感知、规划、执行
- 应用：自动化

- 应用：隐私保护
